# User Stories

## Authentication

As an admin I want to securely log into the platform so that I can manage invoices.

As a user I want role-based access so that unauthorized users cannot access sensitive reports.

## Invoice Management

As an accountant I want to create invoices so that customers can be billed.

As an accountant I want invoice tax calculations so that invoices are compliant.

## Payments

As a finance admin I want failed payments to retry automatically so that temporary failures recover automatically.

As a finance admin I want payment history tracking so that transactions are auditable.

## Notifications

As a user I want email reminders for unpaid invoices so that customers are reminded automatically.

## Reporting

As a manager I want monthly payment reports so that business performance can be monitored.
